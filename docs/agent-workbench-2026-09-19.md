# ColdX 0.1.3：操作工作台、技能与用量

本版把执行过程、浏览器和桌面操作、技能、插件修复以及用量接到原生 DSH 工作流。模型与会话仍由 DSH 管理。

## 使用入口

| 功能 | 入口与行为 |
| --- | --- |
| 行动摘要 | 对话顶部显示当前动作、子智能体、成果与来源数量，点击打开对应面板。长命令使用短摘要，完整轨迹仍可查看。 |
| 工作面板 | 右侧统一使用进度、成果、文件、浏览器、电脑五个页签；宽屏为对话留出位置，窄屏使用抽屉。 |
| 浏览器 | 地址栏、多标签、前进/后退、刷新和真实截图；“手动接管”后可在画面操作，适宽/100% 切换不重新截图。 |
| Windows 电脑 | 开启桌面控制，选择正在运行的窗口并观察；支持鼠标、输入、快捷键和停止。画面更新发生在动作完成后。 |
| Superpowers | 模型强度滑轨左上角的哑铃开关；默认关闭，开启后通过原生技能目录按需读取公开工作流。 |
| 插件安装修复 | 市场中失败任务或没有可验证安装包的项目提供 AI 安装/修复入口，保留任务归属和实际安装状态。 |
| 用量与活动 | 左侧设置上方入口；查看累计/峰值 Token、活跃时长、连续天数、热力图和实际工具/技能使用。 |
| 余额 | Host 向配置上游的同源余额接口查询；默认 CNY 10 / USD 2 以下提醒，可在设置修改。 |
| 应用更新 | 设置中的应用更新，以及发现新版后的侧栏提示；下载完成后确认安装。 |

## 公开 Superpowers 与更新

内置 [obra/superpowers](https://github.com/obra/superpowers) 6.3.0 的 14 个技能，固定版本及 MIT 许可证随包提供。它提供规划、实施、调试、测试、审查与完成验证流程。技能正文按需加载，不把整个库附在每个模型请求里。

技能更新与应用更新分开管理：技能从固定上游检查并下载 Markdown 候选，用户确认装载；正在运行的父子任务继续使用固定版本。应用从 [ColdX Releases](https://github.com/DCM-dc/ColdX/releases) 获取匹配系统和架构的稳定版。桌面版默认自动检查和下载；网页版只检查并提供发行页入口。应用检查间隔为 24 小时，可手动检查。

安装包必须具备 GitHub 发布的大小与 SHA-256 信息，下载后和启动前都核验。启动安装需要确认具体版本；有任务运行时拒绝安装。重复点击不能启动两个安装进程，校验失败保留重新下载入口。当前自动启动安装仅支持 Windows；其他平台提供发行页。实现依据为 [GitHub Release API](https://docs.github.com/en/rest/releases/releases) 和 [Release assets API](https://docs.github.com/en/rest/releases/assets)。

## 数据与操作边界

- 用量来自本地原生会话实际记录，未记录的辅助请求不估算；本地统计不等同于上游账单。缺少缓存或余额数据时显示未知，接口故障不会显示为零。
- 余额密钥只由 Host 读取，查询禁止跨源重定向。不同币种独立显示；不通过余额差猜测单次模型成本。
- 浏览器使用独立上下文，不自动读取用户 Edge 的登录态。桌面支持 Windows 正在运行的软件；未提供任意程序启动器，macOS/Linux 桌面后端尚未实现。
- 手动接管先停止接受新模型动作，等待当前有界动作结束并刷新观察；停止则取消操作并释放自有控制进程，不退出用户软件。
- 微信和 Blender 的操作指南支持模型理解界面流程，但没有在私人微信或真实 Blender 工程中完成端到端任务验收。不能把这些指南称为所有第三方软件都已兼容。
- 公开技能集成、离线回归与控制工具验收不能证明模型生成质量或 Token 成本已有量化提升；本轮没有重跑付费模型性能评测。

## 验证记录

功能验收使用隔离 profile，未复制开发者密钥或私人会话。真实浏览器测试覆盖菜单、侧栏、缩放、深浅主题与窄屏；Windows 使用自建 WinForms 窗口验证真实点击、中文输入、快捷键、拖动和滚轮。PDF 使用公开技术报告验证完整帧替换和尺寸稳定。

独立审查覆盖技能作用域、子任务修复归属、Token 去重、桌面接管和停止、浏览器失败导航，以及应用更新的并发、完整性与重试。复核确认上述问题已经修复。
