## 结论与优先级

ColdX 已有原生 Goal、Plan、子智能体、jobs/workflow、文件上传、执行轨迹和消息原位生成页面。当前更需要把“执行—检查—交付—再修改”连贯起来。不能用工具数量、并行数量或缓存百分比代替最终质量。

| 借鉴对象 | 有证据的优点 | ColdX 的取舍 |
| --- | --- | --- |
| Codex | 文件预览与批注、Git 隔离和差异审阅。[文件](https://learn.chatgpt.com/docs/artifacts-viewer)、[审查](https://learn.chatgpt.com/docs/code-review) | 优先补明确的产物登记与打开/预览，再做与任务绑定的 diff；不要求办公用户理解 Git。 |

建议按以下顺序继续：①产物登记与预览，②Goal/Plan 验收证据，③子任务职责、结果与失败归属，④任务级 diff/worktree，⑤有来源和失效条件的记忆，⑥带执行环境及运行历史的自动化。以上为后续工作，并非本轮已实现。

## 本轮已经实现

| 原来 | 现在 | 用途 |
| --- | --- | --- |
| 不同组件混用玻璃、发光、弹跳 | 实色中性表面、单一青蓝强调、统一圆角与轻边线 | 让内容和状态成为主视觉。 |
| 菜单存在旋转、长弹簧动画 | 按压 140ms，淡入 160ms，工作面板 180/140ms 开关 | 保留反馈，减少高频操作等待。 |
| 行动镜悬浮盖住对话 | 改名“工作面板”，进度/成果与来源两页；宽屏预留 360px，窄屏抽屉 | 空间分工固定，生成页面仍在原消息。 |
| 终端按估算侧栏宽度定位 | 进入 DSH 原生 conversation.input.dock，与输入框等宽、可收起 | 由原生布局量测高度，不再遮挡输入。 |
| 工具栏高度和间距不一致 | 常规控件 32px，触屏规则 44px；窄输入区分行，长模型名截断 | 发送、模型、附件、模式保持可操作。 |
| 同文件反复编辑产生重复产物卡 | 按会话和规范路径聚合，显示最新成功变更并保留调用归属 | 产物计数更接近文件数量。 |
| 辅助脚本/日志/JSON 混在成果中 | .coldx/work 下已识别的过程文件默认折叠，仍可查看 | 减少交付信息噪音，文档和 HTML 保守保留。 |
| 来源绝对/相对路径重复 | 按所属工作区规范化去重，保留每个有效行号和调用 | 证据可追溯；覆盖 Windows、UNC 和 POSIX 根目录。 |
| 将子会话存储状态翻译成“未运行” | 读取真实 running 摘要；缺失显示“状态未载入” | 不把内存/持久化位置误当执行结果，也不推测成功。 |

文件变更显示“已修改/已移动/已删除”，不将写入成功自动视为交付验收完成。已删除文件保留变更记录并取消打开操作。生成页面按会话、页面 ID、revision 区分。

## 组件与布局约定

- 视觉 token：`plugin/client/workbench.css`，最终加载。新增外壳组件使用同一表面、文字、强调色、10px 控件圆角、14px 面板圆角与 8px 间距节奏。主题来自 DSH，不对用户生成 iframe 内容施加外壳样式。
- 原生布局适配：`plugin/client/layout.css`。输入相关控制属于输入框；任务状态贴近原生 composer；辅助检查属于右侧工作面板。根区域小于 940px 时面板改为抽屉，关闭后恢复输入区空间。
- 面板顶部用 ResizeObserver 跟随实际原生 header，高度变化不依赖固定像素猜测。保留 DSH 的 conversation/session/details 所有权，不替换整个原生组件。
- 通用动效：`plugin/client/motion-source.mjs`。常用操作默认短淡入，无回弹；保留 reduced-motion 和高对比度支持。
- 过程信息只来自公开的原生投影。侧栏不从任意终端文本猜文件成功、不从计时或父任务结果推测子任务完成。

## 尚未补齐的边界

1. 终端仍显示工具结束后返回的输出，不是实时流式 PTY，也不是可输入的 shell。
2. 通过 shell 隐式生成、没有 typed mutation/page 投影的文件还不能自动进入成果列表；需要正式产物登记接口。当前列表不是整个工作目录的完整文件清单。
3. 来源和产物的通用文件预览/批注入口尚未接通；本轮先整理展示与状态，保留原生消息中的文件查看入口。
4. 单次子任务的详细成功/失败结果需要原生结果投影，不能由“当前没有运行”推导。
5. 布局适配针对固定 DSH rc.2；升级原生客户端时须重验 slot、类名、窄屏、审批接管与滚动行为。macOS/Linux 桌面包本轮未重新构建。
