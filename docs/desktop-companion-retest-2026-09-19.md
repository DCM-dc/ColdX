# ColdX 卸载与桌面伙伴复测

> 历史验收记录。2026-09-20 用户明确取消桌面宠物，相关窗口、IPC、设置与桌面专用测试已从开发分支移除。当前产品方向见 [应用内小绒蜂巢](./superpowers/specs/2026-09-20-in-app-hive.md)；本文中的桌面能力不再是现有功能。

日期：2026-09-19。按用户最新要求，卸载已安装的 ColdX，再使用独立数据目录测试开发版本。本轮没有重新安装或发布版本。

## 卸载与数据

- 已调用 ColdX 0.2.1 官方卸载程序。安装目录中的程序、卸载注册项、桌面快捷方式均已移除。
- 用户聊天和配置保留在原 AppData 目录。卸载前备份，卸载后再次校验 47 个数据文件，SHA-256 均一致。
- 测试使用单独的 `.runtime/companion-browser-home` 与 `.runtime/companion-desktop-data`，没有使用用户正式会话。
- 结束时关闭临时浏览器页、测试桌面窗口和测试后端；电脑保持卸载状态。

## 本轮复现与修复

1. 子智能体结算通知可能误中断父任务正在进行的工具循环。仅拦截独立结算通知触发的空转，保留父任务正常工具续跑。
2. 电脑控制模块错误解构原生 `agent/disposed` 事件，子任务结束时可能导致后端退出。按原生 `{agent}` 事件清理并等待清理结果。
3. 普通多行回复和原生 `one-shot` 子任务被桌面快照校验拒绝。显示文本统一成单行，支持原生模式；身份字段继续严格校验。
4. 桌面 IPC 拒绝未处理。现在显示可恢复错误并重试，旧请求不覆盖新状态。
5. 桌面周期刷新会重置点击区域与窗口几何；现在复用节点，仅在尺寸改变时调整窗口。
6. 团队历史容量边界不一致。读写统一使用容量上限，并覆盖完整中文历史的持久化测试。
