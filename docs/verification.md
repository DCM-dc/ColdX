覆盖真实 DSH Cordis 插件生命周期、原生 Gateway 与 Agent 归属、Code Mode 嵌套调用、question carrier、普通问题与多选回传、完成状态失效、取消与卸载、投影回放和启动配置。动效测试覆盖快速打断、旧回调失效、键盘与减少动态效果。样例实验台的底层回归仍保留，但该产品入口及对应 Host 工具已经停用。

协议清理器不再把私有结束标记、泄漏的 idle reminder 或损坏的 DSML 尾段改写成可重试的 `EMPTY_RESPONSE`。它只隐藏控制内容，保留已有可见正文并透传原生 stop；marker-only 与纯损坏协议也直接结束为空。完整 Host 回归覆盖“正文 + 私有结束标记”仅产生一次模型请求，旧轮曾提及标记不会让后续泄漏永久放行；流式回归还覆盖大量尾部空白、逐字符分片以及没有 `block-end` 的 delta-only 适配器。有效 DSML 转成真实工具调用后的下一步仍是正常工具结果续跑。

生成页面运行在 `sandbox="allow-scripts"` iframe 中，无法访问父页面 DOM/存储；提交只结束绑定的原生等待。明确纯文字要求、取消、已有结果页与跨轮边界由测试覆盖。原生 Markdown 渲染真实最终文字；结果投影不伪造工具调用，也不增加模型请求。
