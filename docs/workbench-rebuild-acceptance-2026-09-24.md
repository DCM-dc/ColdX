## 实际交互证据

使用独立 `.runtime/rebuild-ui-home` 与 `.runtime/kernel-ui-work`，未改用户正式配置或聊天数据。模型为本地确定性 `coldx-ui-fixture`，没有调用收费模型。

- 原生输入请求 → 流式回复 → 点击 Markdown 文件链接 → 右侧渲染 → 引用回输入框；真实键盘输入与清空正常。
- 置顶后刷新仍保留；原生重命名保存后显示“工作台验收”；菜单方向键与 Escape 焦点归还通过。
- 新对话开启 Goal/Plan，两个标签同时显示且不额外创建会话；900×700、1280×800、2048×1076 视口检查。
- 深浅主题切换，文件侧栏与设置随之变化。
- 用只出现在正文中的“未调用收费模型”搜索，命中原生历史；服务重启后仍有效。
- 周期任务创建/读取/取消通过。单次任务在北京时间 22:54 自动产生原生 `schedule` 唤醒与回复；随后列表为空，没有遗留循环任务。
- PR 缺少 CLI 的回退页面通过；社区插件目录通过；模型滑块的拖动、键盘、慢保存与失败重试浏览器回归通过。

## 本次一并修复

原生 settingsScope 的接收者与 `set(field,value)` 调用错误、重命名弹层被提前清空、默认未开启正文索引、原生 schedule 依赖存在但模块未激活、模型信息按钮覆盖 Superpowers 开关、未闭合代码围栏和跨文本块同名文件链接混淆、侧栏折叠后的重复搜索入口。

Superpowers 检查更新原先读取完整 commit（含文件差异），会触发响应体限制。现在读取有 16KiB 上限的 Git ref，再按不可变 SHA 读取版本；下载、完整性校验和确认装载流程保持原样。真实 GitHub 只读检查已发现 6.4.1 候选，未自动激活。页面中的后续候选下载遇到网络 `fetch failed`，当前显示“下载候选”重试入口；本轮不将下载或装载计为成功。
