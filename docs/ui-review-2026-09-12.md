# ColdX 界面一致性审查（2026-09-12）

本项审查覆盖侧栏、会话顶部工具、设置导航、原生菜单、文件工作区、终端、工作面板及电脑画面控制。目标是减少视觉分歧，并让常用操作在键盘、窄屏和触屏下可达。输入框、模型控制、品牌标识由本轮其他改动负责；本文件不把它们计入本项验证结果。

实现放在 `plugin/client/ui-consistency.css`，复用 `workbench.css` 的颜色、圆角与层级变量，不新增主题 token。该层应在现有组件 CSS 之后、输入框与品牌的专用 CSS 之前加载。行为改动包括 `file-view-source.mjs` 的文件夹筛选空状态、当前文件标签水平可见性，`activity-source.mjs` 的工作面板内容分层，以及独立 workspace 原生包补丁中的会话树键盘导航。工作面板宽度调整仅修改 `layout.css` 的面板相关段；后端、DSH 会话/工具/权限执行逻辑不变。

## Before / After / Why

| 范围 | Before | After | Why |
| --- | --- | --- | --- |
| 侧栏会话操作 | 原生 `rowActions` 使用 `display:none`，只有 hover/menuOpen 时出现；行本身是未设置 `tabIndex` 的 `treeitem`，键盘无法先进入隐藏按钮 | 操作容器保留布局与键盘焦点，平时透明，hover/focus-within/menuOpen 时显示；无 hover 设备常显 | Tab 能直接进入原生操作菜单，触屏不需要模拟悬停。仍使用原生菜单和操作 |
| 会话树键盘导航 | 原生工作区/会话行没有 `tabIndex` 和行级键盘处理；搜索结果虽是 button，也没有方向键导航 | 行可通过 Tab 聚焦；Enter/Space 触发原生打开/折叠；上下/Home/End 导航当前树的可见项；右键展开或进入首个子会话，左键折叠或回到父工作区 | 完成本轮要求的会话导航。只处理焦点行自身事件，忽略菜单/输入、IME、修饰键，避免改写重命名或搜索输入行为 |
| 侧栏按钮 | 原生图标按钮只有 16×16，行操作容器间距 12px | 常规按钮 28×28、操作容器 32px；触屏 44×44、间距 4px | 增大实际命中区域，减少无意义空隙，并避免触控图标难点中 |
| 顶部文件/工作面板入口 | 顶部同时放置“文件”和“工作面板”，两条路径最终打开相同侧栏 | 从组件树删除独立“文件”按钮，浏览入口统一为“工作面板 → 文件”；首次打开列出工作区根目录 | 减少重复入口及 Tab 焦点；文件组件、持久预览、成果/来源/消息文件链接和引用能力仍保留 |
| 设置当前分类 | 现有 workbench 覆盖让导航背景和 active 分类背景都变成 raised | active 使用共享 selected 背景和 600 字重 | 当前所在分类有清楚、稳定的层级 |
| 窄屏设置导航 | 两列分类网格随分类数量增高，挤压实际设置内容；原生还定义了纵向 flex | ≤640px 显式切换为单行横向滚动分类，保留标题、标签和原生按钮 | 将主要高度留给设置内容。键盘聚焦由浏览器滚动至相应按钮 |
| 原生菜单 | compact 项 33px，控件圆角存在 7/9/10px 差异 | 使用共享控件圆角，compact 项至少 34px，菜单最大宽度受视口约束 | 减少二级界面的几何差异。未对根菜单强加 overflow，以免截断子菜单 |
| 工作面板布局 | 面板 380px；标题行同时放标题、调用/子任务/来源计数，内容内外又重复 padding | 桌面默认 440px，较宽会话区 460px；只保留标题和关闭按钮；标题、tabs、主要内容使用单层 20px inset；计数放到各自分组 | 在 1280px / 左栏 280px 时仍留 560px 对话，保持侧边预览；会话区小于 960px 才切为原生抽屉 |
| 当前进度 | 最近行动使用大色块，长 shell 命令在主视图截断 | 中性状态点、次要标签和两行以内摘要；命令显示“正在运行命令/命令执行已结束/命令执行失败”，完整原生公开命令保留在操作详情 | 当前工作一眼可读；不把命令正文伪装成自然语言任务结论，不推断任务整体成功 |
| 子任务 | 长英文任务名和状态挤在同一行；原始标题截为 32 字符 | 有界首行任务名最多 72 字符，允许换行；真实状态独占下一行，失败原因沿用原生 outcome 映射；数量独立放分组末端 | 可以识别具体任务，仍不输出完整委派 prompt 或隐藏推理；点击继续使用精确父/子会话身份 |
| 操作历史 | 每个已结束调用都铺成灰底卡片，主面板高度随历史快速增长 | 当前操作置顶；结束的操作默认折叠成一行，显示记录数和失败次数，展开后为平面时间列表；父/子调用任一未结束时保留在当前区 | 历史不抢占首屏，失败也不会因折叠消失；全部已加载记录、命令详情仍可查看。返回当前改为回到顶部，展开历史暂停自动跟随 |
| 成果与来源 | 每条记录都有浅底圆角，分组内套多层卡片；正文/元信息出现 10.5px 小字 | 改成分隔线列表；标题 13px、元信息与来源摘要 12px；过程文件和历史仍可展开 | 长任务更容易扫描，减少重复卡片带来的装饰密度；真实状态、来源路径和打开操作仍在 |
| 文件控件与状态 | 文件按钮使用 6/7/8px 圆角；focus 固定 `#4597b1`；定位行固定蓝底；错误与提示共用黄色 | 统一控件圆角；focus/定位行跟随共享主题；错误使用原生 error 色，普通提示使用中性 raised 表面 | 深色、主题色与高对比状态保持一致，同时区分失败与一般说明 |
| 文件夹筛选 | 非空目录筛选无匹配时，只显示空白列表 | 显示“没有匹配的文件。请尝试其他名称。”；真正空目录显示“文件夹为空。”；清空筛选恢复列表 | 用户能区分过滤结果与加载失败/空目录；状态使用 `role=status` |
| 多文件标签 | 打开较多文件后当前标签可能位于横向视口之外 | 切换文件时只调整标签条 `scrollLeft`，将当前名称及关闭按钮一起带入视口 | 当前文件与关闭入口始终可见；不使用会滚动整个对话或预览文档的 `scrollIntoView` |
| 终端 | 面板仍有进入缩放动画，运行中圆点持续扩散光圈；正文 11px，记录表面独立混色 | 去掉终端进入和循环光圈，保留真实状态色；正文/命令 12px；记录、输出、收起按钮使用共享中性表面 | 连续命令输出应便于阅读，避免把注意力吸引到装饰动画；输出流和执行生命周期不改 |
| 触屏与键盘 | 文件、工作面板 tabs、电脑画面部分操作仍是 30–32px，部分新增按钮缺少明确 focus 规则 | 常规控件至少 32px，触屏主要操作至少 44px；文件搜索/源码、历史折叠、电脑控制补主题 focus | 浏览、复制引用、切换成果和关闭画面具有一致的操作反馈 |

## 验证证据

命令：

```text
node --test test/sidebar-keyboard.browser.mjs test/ui-consistency.browser.mjs test/activity-panel.browser.mjs test/file-workbench.test.mjs test/file-view.test.mjs test/workbench-pane.test.mjs test/activity-components.test.mjs test/activity-model.test.mjs test/workbench-css.test.mjs
```

上轮整体审查执行为 **49 个测试通过，0 个失败**。其中浏览器回归使用当前 DSH 依赖的真实 React 18.3.1、实际 workspace/settings-general 包中的 CSS，和官方 Playwright 的独立 Chromium。新增会话树回归装载完整原生 Workspace、Client Runtime 和 Primitives；工作面板回归装载真实 Activity/Frost/File/Workbench 组件 factory；测试回调只记录浏览器内存中的导航/重命名，没有操作用户现有浏览器、业务会话或数据库。

浏览器回归检查：无 `tabIndex` 的原生结构中 Tab 可直接进入侧栏菜单；操作按钮焦点可见；12 个文件标签下当前名称和关闭按钮都在可见范围；往回切换首个文件仍可见；375px 设置分类维持单行可滚动；深色、forced-colors 和触屏命中区域；终端没有进入/循环动画。文件组件回归保留了 PDF/HTML 预览实例、切换工作面板、关闭进行中的单个文件读取、会话引用归属等既有行为。

筛选无匹配与当前文件关闭按钮可见性均先观察到回归失败，再修复至通过。浏览器检查还发现原生 settings 的 `flex-direction:column` 会继续生效，随后补上明确的 `row` 并重新验证。

工作面板新增回归检查：1280px 视口中面板实测 440px、对话 560px，桌面保持非模态；375px 时原生模态抽屉不溢出；标题行不含计数条；子任务标题和状态实际矩形不重叠；8 条结束操作默认不可见，Enter 展开后全部可见；长命令只在详情中完整显示；打开子会话、页面和来源文件的精确身份不变；进度 → 文件 → 进度过程中只有一个可见面板，文件内容正常；Esc 关闭及焦点还原。人工查看了以下独立组件回归截图，确认长英文任务名正常换行、没有连续大底色卡片。截图中的任务和内容是测试 fixture，并非真实用户任务的完成证据。

## 已检查边界与未完成项

- 本项未 build/restart；主任务需将 `ui-consistency.css` 纳入最终构建，再在完整运行页面做本轮总体验收。上述独立浏览器结果不能等同于所有线上页面逐屏验收。
- 本轮要求的行聚焦、激活和方向键导航已完成。此补丁使用逐行 Tab，同时保留行内菜单按钮可达；未把原生树重构成只有一个 Tab 入口的 roving tabindex 模型，也未新增名称首字母检索。它是明确键盘操作范围的修复，不是对全部屏幕阅读器行为的认证。
- 设置仅审查和调整导航、滚动、当前分类、通用控件以及既有窄屏布局。未遍历每个已安装插件的所有动态设置页，未读取/改动提供方凭据。原生权限、危险操作和错误语义保留。
- 工作面板已有真实调用/来源投影、分组与子任务生命周期。本项改变分层、折叠和跟随方向；不会把 shell 隐式产生但未登记的文件推断为成果，也不补造状态。结束列表的计数是已加载操作记录数，成果分组使用既有规范路径去重；这两种计数不混用。宽度本轮固定为 440/460px，没有新增拖拽调整器。
- HTML/生成页面 iframe、PDF 内容本身不属于此样式层。未修改它们的字体、作者布局、脚本或文件访问边界。
- CSS 模块名来自固定 DSH 0.1.1-rc.2；升级原生 frontend 时应重新运行本回归。桌面各操作系统的字体渲染及移动设备真机测试尚未覆盖。
