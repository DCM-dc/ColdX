## 行为接入

- `conversation.input.add` 提供原生输入快照、输入动作及当前选择位置。ColdX 未挂载时仍使用原生加号。
- 插件列表读取会话范围内的原生 `skills.list`。点击通过原生 `slash/input-insert-text` 插入，校验会话、目录和草稿版本；保留已有文本、附件、光标和撤销历史，不自动执行任务。
- 当前实际目录有 `cordis-plugin-development`、`editing-cordis-compositions` 两项。截图中的六项示例插件未被伪装成已安装功能。
- 本机文件、原生图片及工作区引用复用已有上传和引用接口。模式切换复用既有草稿状态，发送前才同步到会话。
- 模型滑块使用真实 Off / Low / High / Max 档位；本机当前模型默认值为 High，验收会话原选择为 Max。保存会触发目录后台刷新，刷新时通过 `aria-disabled` 与事件守卫避免重复提交，同时保留 DOM 焦点。

## 当前模型控制卡：细刻度设计

按用户后续“自己设计”的要求，模型卡片改为约 304×139px。顶部是可切换的模型名称与重置；中间显示“推理强度”和当前档位，保存期间在档位旁提示；底部用 8px 细轨道、真实档位刻点和 24px 拇指。整条命中区域为 40px，触屏增至 44px。无可见底部说明，屏幕阅读器仍可读取操作提示；真正的设置错误保留重试入口。

| Before | After | Why |
| --- | --- | --- |
| 档位大字、闪电和模型名集中居中 | 模型名称、强度设置分为两行，重置位于右上角 | 明确“选择模型”和“调整强度”的操作层级 |
| 30px 渐变轨道与 32px 白色拇指 | 8px 中性轨道、24px 拇指与真实档位刻点 | 降低装饰密度，使档位与操作位置更清楚 |
| 整条滑块外圈显示键盘焦点 | 焦点环只围绕当前拇指 | 清楚标识正在调整的位置，避免双层进度条视觉 |
| 最高档持续循环粒子 | 成功调至最高档时仅出现一次 240ms 微粒反馈 | 保留操作反馈，静置或载入原本为 Max 的设置时保持安静 |

透明原生 range 保持键盘、焦点、指针捕获及真实档位选择；原生拇指、装饰拇指及跟手坐标统一为 24px。拖动时连续跟手，松手后用 180ms ease-out 吸附到实际支持的档位，只在松手/按键释放时保存。满档成功反馈使用 6 个微粒，动画结束后卸载，没有额外请求或 JavaScript 动画循环。减少动态效果时隐藏微粒、取消空间移动。

加号菜单恢复 170ms、6px 的短距离淡入/淡出，支持快速反向开关；键盘关闭立即完成，退出期间不可交互，200ms 清理兜底。工作面板恢复 200ms、12px 的横向淡入，切换面板内容不重复滑入；原生 dialog 继续负责焦点与模态。普通按钮保留约 140ms、2% 的按压反馈。

原生浏览器回归新增：拖出卡片边界后松手仍只保存一次且保持菜单/焦点；离散档位之间视觉拇指与鼠标相差小于 1px，松手后归位到真实档位；满档粒子在实际浏览器中改变姿态后卸载；减少动态效果无持续动画；卡片正常状态高度在 90–140px 内，底部说明不占布局。工作面板尺寸检查等待动画结束后进行。运行中页面已实际查看新的细刻度卡片。

与 PDF 修复统一集成后，最新构建和回归为 434 项单元测试、14 项浏览器测试全部通过，覆盖本节的新滑块、PDF、工作面板及输入框布局。日志为 `.runtime/slider-pdf-final-unit-20260912.log` 与 `.runtime/slider-pdf-final-browser-20260912.log`；这次联合浏览器集合与上文早期验收集合不同。新卡片截图为 `outputs/ui-review/model-control-compact.png`，运行中的真实模型卡片也已查看。PDF 的故障证据及现场验收见 [PDF 预览修复](pdf-preview-reliability-2026-09-12.md)。

## 保存反馈闪烁修复

“保存中”原先随每次请求立即挂载显示，且临时 `aria-disabled` 使模型名和重置按钮瞬间变淡。现在提示由 CSS 延迟 600ms 后用 120ms 淡入，快速保存不显示；没有 JavaScript 提示计时器。临时保存/刷新仍通过原生状态和事件守卫阻止重复操作，但不降低控件亮度；默认值的重置按钮仍有禁用外观，失败仍立即显示可重试错误。

同时修复原生保存与目录刷新重叠时的档位回跳：仅在保存被接受且对应目录快照还处于 loading 时保留确认值，刷新结束/失败、新快照、会话或模型变化后失效。该显示状态不发送额外请求，不改变原生保存语义。

验证：435 项单元测试通过；原生 ModelDirectory/ModelSelect 浏览器回归通过，包括短保存 200ms 内逐帧不可见提示且标题不变淡、慢保存提示出现、等待目录期间无档位回跳、菜单/焦点保持、失败重试及旧确认值不能在后续加载复活。运行页面实际 High/Max 切换并恢复原 Max，菜单保持打开。日志为 `.runtime/model-saving-feedback-unit-20260912.log` 与 `.runtime/model-saving-feedback-browser-20260912.log`。
