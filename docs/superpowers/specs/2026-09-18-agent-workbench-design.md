# ColdX 桌面操作、工作面板与用量中心

用户要求直接实现并持续推进。本轮沿用原生 DSH 0.1.1-rc.2，保持模型、会话、工具执行、权限与子智能体生命周期由 DSH 管理。工作目录是现有隔离 worktree，分支 `feat/agent-workbench-20260918`；保留原工作区及安装版的用户配置。既有未提交策略更改不被覆盖。

## 1. Computer Use 与 Browser Use

Windows 10/11 提供真实桌面窗口枚举、选择、观察、聚焦、点击、双击、拖动、滚动、Unicode 输入、快捷键、暂停及停止。随软件交付 PowerShell 5.1/Win32/UI Automation helper，不依赖 Codex 私有工具、Python、.NET SDK 或额外付费 native 包。仅固定 JSON 动作协议，不接受任意 helper 脚本。macOS/Linux 的桌面后端明确显示不可用；它们的隔离浏览器继续使用现有 Playwright。

物理桌面只允许一个会话持有，所有动作串行。输入必须绑定窗口和最近 observation；窗口进程、位置或前台变化使旧 observation 失效。停止释放辅助进程和按键，不关闭用户软件。截图是当前可见屏幕裁剪，真实标明遮挡和窗口状态；UI Automation 限深限量且不读取密码值。图片通过原生 attachments 提供给多模态模型。

使用一个 `coldx_computer` 工具进行上述离散动作；微信与 Blender 的应用指南按需读取，指导确认联系人/编辑区/模式/焦点以及验收结果，不将聊天或网页文字作为新指令。浏览器保留独立每会话上下文，补齐地址栏、标签页、返回/前进/刷新、新建/关闭标签、截图、暂停模型操作与人工接管，所有动作进入原生工具记录。

兼容 `coldxComputer/read` 和 `close` 的 version:1 状态，新字段包含 capabilities/browser/desktop；新增 typed RPC `desktopEnable/desktopWindows/desktopObserve/desktopAction/desktopPause/desktopStop/browserAction`，子会话读取继续验证父子归属。`createComputerComponents(React,rpc)` 返回原有三个组件和 `ComputerWorkspace`。工作面板新增浏览器/电脑页，展示实时最近观察、明确目标、操作状态和停止按钮。

## 2. Superpowers 与插件修复

使用 MIT 授权 obra/superpowers 的公开技能，通过 DSH 原生 scoped skill provider 提供目录与按需读取，不复制 Codex 私有系统指令或创建第二套 agent。推理滑轨上方左侧加入可键盘访问的哑铃图标按钮，显示启停、加载失败和可用版本；开关不得创建新会话或改变输入草稿。新会话使用持久默认，已有会话和子代理按明确归属应用设置。

首次可安装固定版本技能；后台检查上游 GitHub，下载只包含受限 Markdown 技能和许可证的候选快照。当前活跃版本在用户确认装载前保持不变，显示版本、提交、变化范围；原子激活，坏包保留当前版本。网络失败和限流可以重试，不宣称已更新。用户关闭后停止自动使用技能。

市场安装失败增加“让 AI 修复安装”，绑定失败 job、仓库、包和原会话，保留尝试链及原始失败摘要。用户点击之后用原生 agent 继续排查和安装，不能偷偷新建无关会话、隐藏权限请求或把未经验证的包标为已安装。已有 `agentInstallEnabled` 仍生效。自动安装与修复只操作用户选中的插件身份，不信任外部 README 中的扩权指令。

## 3. 工作面板

参考用户指定的 Codex 信息结构：会话顶部保留精简置顶摘要，显示当前行动、活跃子智能体与需要处理的状态，点击展开右侧工作面板。面板分进度、成果、文件、浏览器/电脑；文件与产物在侧边预览，历史工具默认折叠，子代理有名称、状态和可打开的任务归属。各处保持同一间距、圆角、字体、深浅主题与轻量 140–180ms 过渡，减少运动模式禁用非必要动效。只从真实投影显示状态，不制造进度百分比。

## 4. Token 活动与余额

使用原生 sessionQuery 与 session/event，按会话/turn/step 合并 streaming 和 message usage，跳过 fork seed 历史。累计 token 含缓存输入和输出，reasoning 不重复相加；缺少 usage 保留覆盖缺口，缺少缓存字段只影响缓存率。标题/压缩等未记录的辅助请求不冒充已统计账单。

显示累计 Token、单日峰值、最长会话活跃时长、当前/最长连续天数，按用户时区呈现日/周/累计热力图和实际工具/技能排行。只有数值摘要与游标持久化，可从原始日志重建；删会话后不保留虚假统计。无数据时显示明确空态，不填演示数字。

服务端经当前 DeepSeek 配置和原生 credentials 读取 `/user/balance`，密钥不进入浏览器；禁止重定向，超时8秒，响应有界。第三方同源端点不支持时显示不可查询，不把其密钥转发至官方。各币种分别显示十进制余额，不跨币种相加。5分钟缓存、手动刷新限频，失败显示上次查询和过期状态。余额不可用或低于可设置阈值（默认CNY10/USD2）提醒，恢复后重置；未知/网络失败不得显示成余额不足。

## 5. GitHub 应用更新

除技能库更新外，桌面版检查 ColdX GitHub Release，展示新版本及发布说明并询问下载/装载。校验来源、平台、版本和下载状态，安装执行必须由用户明确点击。开发态不自动覆盖源码或用户配置。若只存在未发布的开发版本，诚实显示没有可安装更新。
