# 小绒蜂巢：应用内协作与成长

用户目标：小绒提供更多情绪价值，参考蜂群和经验基因；最新要求明确砍掉桌面宠物。仅在应用内显示，不恢复安装、不创建置顶悬浮窗。用户此前要求全程自主推进，此次按该授权制定与执行设计。

## 研究与取舍

- AutoGen Swarm 使用能力相关的交接与终止条件：https://microsoft.github.io/autogen/dev/user-guide/agentchat-user-guide/swarm.html
- EvoMap 文档将分解求解、发散收敛、结构化对话、共享任务板和经验资产称为蜂群能力：https://evomap.ai/zh-hk/wiki/10-swarm 。这些是项目自述，不当作独立性能证明。
- Sakana DGM 的进化包含候选变更、实测评估和版本档案：https://sakana.ai/dgm/ 。保存一条建议不等于模型训练或性能提升。

此次延伸现有原生子任务队伍：并行探索 → 审阅伙伴接力汇总 → 有来源的候选经验。不是完全去中心化蜂群，不增加无限自治循环，不自动改写程序或模型权重。原有只读团队权限保持。选择这一方案，因现有真实 native 子任务可直接承载，而完全分布式调度、代码自修改需要单独评测体系。

## 产品

2026-09-20 用户复看后修订：普通会话列表下新增“群组”，点击在主区域展示普通群聊。移除蜂巢弹窗、大舞台和成长主页；成员使用小绒头像、名字与状态，消息按普通对话排列，经验放在可展开资料中。眼睛保持固定尺寸，情绪通过短暂眨眼、视线、嘴型表达，取消状态持续压扁眼睛。

集成使用原生 `sidebar.footer.action` 列表槽和仅在选中群组时存在的 `conversation` 单槽贡献；离开群组恢复原生会话。群组选择与普通会话选择互斥，保留原会话和草稿。无需桌面窗口、DOM 传送门或全屏遮罩。

群组可从列表选择或新建。默认研究/设计/审阅三位不同颜色伙伴，可调整至 1–4 位。正文使用正常聊天的头像、名字、文本和打开任务入口；底部固定输入框。普通会话与群组选择互斥，切换保留各自草稿。

标题和侧栏显示真实阶段，头像指向原任务。等待确认优先显示，摸摸不掩盖等待。使用明暗主题变量、窄屏堆叠、键盘可用、减少动态效果、后台暂停装饰动效。情绪短句描述事实，不虚构思考、进步值或人际依赖。

可展开的“群组信息与经验”展示模型从本轮公开结果提炼的经验：标题、适用条件、做法、来源任务、使用次数、候选/试用中/已停用。只有用户选择试用后才供同一团队后续轮次使用，可随时停用。未产生候选时说明原因，不生成虚假经验卡。

## 数据与接口

现有 snapshot version 1 向后兼容。team 可增加：
```
round: {id, phase:'exploring'|'synthesizing'|'settled', startedAt, finishedAt?, reviewerId?}
genes: [{id,title,when,practice,status:'candidate'|'active'|'paused',sourceTaskId,sourceMessageId,roundId,createdAt,uses}]
```
新增 `updateGene({teamId,geneId,status:'active'|'paused'})`，仍通过原生 `coldxCompanion` Typert RPC，父任务所有权校验。每团队至多 12 条基因、最多 3 条 active；每次最多使用 2 条，合计上下文不超过 1200 字符；无跨任务共享。

原有 N 次成员任务加至多 1 次汇总任务，不另开提炼任务。这里计数的是原生子任务轮次，不是 API 请求；子任务可多步调用模型和工具，每轮每成员合计上限 12 步。汇总优先选 role=review 的成功成员，其次首个成功成员；汇总提示可附一个 `coldx-gene` fenced JSON（title≤60、when≤180、practice≤400）。合法元数据从群聊显示中移出，来源完整保留； malformed 内容不作为经验执行。仅全员和汇总实际完成时保存候选，失败/取消不产生成长记录。使用次数只代表被送入后续执行的次数，不代表实测成功率。

删除 desktop/companion-*、desktop 伙伴资产、IPC bridge、启动/退出挂接、相关桌面专用测试，以及 desktop/reminders 设置。保留所有正式聊天与此前备份。已有设置中的旧字段被安全忽略。

## 验收

原生测试覆盖 reviewer 交接、停止/失败不生成候选、候选解析、采纳/停用与下轮有限注入、保存/恢复和旧版本迁移。浏览器覆盖普通群组列表和聊天、真实阶段、经验操作与失败反馈、浅深色/窄屏/减少动态效果、草稿和来源导航、各状态固定眼睛尺寸。构建与完整回归必须通过。测试仅使用本地模型替身，付费模型质量提升不作未经测量的声称。
