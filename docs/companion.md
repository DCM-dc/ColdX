# 小绒：一个安静的毛球伙伴

小绒住在侧栏底部，可以点击或按 Enter 摸摸它。大眼睛会看向鼠标，偶尔眨眼；点击有轻微的挤压、弹跳和一句短回应。收起侧栏时保留一个小毛球。

在「设置 → 通用设置 → 小绒 · 毛球伙伴」开关。毛球旁的关闭按钮也会保存关闭状态。偏好使用 DSH 原生全局设置 `coldx-companion.enabled`，默认开启，与终端设置独立。保存失败会显示错误并保留当前状态。

## 交互边界

- 陪伴全部在本地运行，不发送消息、不调用模型、不增加提示词，也不消耗模型 Token。
- 使用当前会话的原生运行、等待和回合错误状态。只换表情和短句，不承担运行状态面板的职责。
- 停止、取消、切换会话和打开历史会话都不会被宣称为任务成功。结束后回到安静待机。
- 不发声音，不自动弹窗，不遮挡对话或输入框，没有打卡、饥饿、催促或连续使用奖励。
- 支持深浅色、键盘与触摸；尊重系统减少动态效果，页面隐藏时暂停动画，关闭时卸载监听器。

## 实现

`plugin/client/companion-source.mjs` 是独立的原生客户端组件工厂，挂入 `sidebar.footer.action` 与 `settings.general.item`。会话标题区中的无界面观察器只转发状态变化，不遍历历史，不轮询后端。流式文本更新不触发毛球状态刷新。

`plugin/client/assets/companion-source.png` 是为 ColdX 生成的原创透明底毛球素材。没有使用用户参考照片作为分发素材。`scripts/build-companion-asset.mjs` 构建时缩小为 256px PNG 并嵌入客户端；眼睛与表情由 CSS / DOM 实现，按压使用可中断的 Web Animations API。

## 验证

- `test/companion.test.mjs`：运行/等待/错误、取消不报成功、会话所有权、流式更新去重、摸摸不掩盖错误。
- `test/companion.browser.mjs`：真实 React 组件、鼠标/键盘、保存失败、开关、窄侧栏、深浅色、减少动态效果。
- 本地独立 DSH 验收环境：原生侧栏显示、点击、关闭后刷新保持关闭、从通用设置恢复、深浅色和折叠侧栏、模拟回复运行时状态切换。未调用收费模型。
